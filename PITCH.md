# Five-minute table pitch (peer review, Sun 15 Nov)

Set-up: laptop shows tieto.psavela.com/table (QR). Second tab: /play. Third tab: /cases.

| Time | What happens |
|---|---|
| 0:00 | "An AI wrote this pull request. Would you sign it?" Reviewer scans the QR, or takes the laptop. |
| 0:20 | **Round 1** (45 s): they scroll the real 238-file diff and choose. Most approve. |
| 1:10 | **Reveal**: "You approved two problems." Point at the red cards. Neither is caught by a test. |
| 1:30 | **Round 2** (~20 s): same change with the case file. Two questions, sign. |
| 2:00 | **Result** + crowd numbers: "N% of reviewers today approved it blind." |
| 2:20 | **How it works** (/cases): machine proofs first, policy files refused, one AI call, quotes verified, rules route to a named owner. |
| 3:30 | **Why it's safe**: AI never approves; no proof, no claim; refuses business decisions; signature locked to the commit. |
| 4:10 | **Honest limits**: run-to-run variance; tests not run; AI and agent share blind spots, so the deterministic checks matter. |
| 4:40 | Close: "AI reviews. You stay accountable." |
